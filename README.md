# Học Bá ⚽

App ôn thi **Anh văn cấp độ 3** (thi Chủ nhật 22/11/2026).

## Có gì trong app

- **Lịch học:** lịch từng ngày từ 18/10 đến 22/11, mục tiêu tuần, tiến độ.
- **Từ & Ngữ pháp:**
  - 532 thẻ từ, ôn cách quãng (app tự hẹn ngày ôn lại từng từ).
  - 16 bài ngữ pháp và 3 bài Cách dịch.
  - Luyện dịch mỗi ngày 3 câu.
- **Đề thi:**
  - 15 đề luyện, 4 đề thi thử, tổng 952 câu, mỗi câu có giải thích riêng.
  - Chấm điểm ngay sau mỗi câu, dịch câu hỏi theo cụm, giải thích theo 3 mức dễ hiểu.
  - Bảng câu sai: câu nào làm đúng ở 3 ngày khác nhau thì tự rời bảng.
  - Tải thêm đề mới hoặc từ vựng từ file Word hoặc PDF.
- **Đồng hồ học:** chọn số phút học và nghỉ, hết giờ có chuông báo.

## Các file trong thư mục

| File | Là gì |
|---|---|
| `streamlit_app.py` | File khởi động app |
| `hocba_app.zip` | Toàn bộ app: code, đề, từ vựng, bài học. **Không giải nén**, để nguyên |
| `requirements.txt` | Danh sách thư viện app cần |
| `.streamlit/config.toml` | Màu sắc của app |

Hướng dẫn đưa app lên mạng nằm trong file `HUONG_DAN.md`.
